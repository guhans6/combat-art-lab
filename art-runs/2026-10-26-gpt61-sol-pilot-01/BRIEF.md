# Frozen benchmark brief

Improve the head likeness of the copied standing-v03 sprite toward the approved
close-up and scene. Inspect actual reference images before diagnosing differences.
Test eye spacing, near/far eye proportions, head direction, cheek/chin, expression,
ear coverage, fringe and tied-hair silhouette. Record observations before editing;
there is no predetermined ideal eye gap or required movement direction.

Work only on work/candidate.aseprite and new pass files. The task.json profile
specifies the native canvas, permitted layers, mask, reference priority and budget.
Keep the neck and everything below it unchanged. Keep the existing palette and
pixel construction; small meaningful facial pixels are allowed. Do not replace
this task with an image-generator redraw or a resized reference import.

Read the pixel-art-director skill and its face-likeness branch. At each pass,
export and inspect both native scale and nearest-neighbor head detail. Verify
zero changes outside the mask and protected native layers. Deliver native source,
transparent PNG, comparison, patch log, checks and an honest unresolved-gaps note.
Preserve all candidates. A passing validator is not visual approval.
