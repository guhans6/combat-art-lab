# Current A — 152px and lighting study

The user prefers152px as the current display height. This separate project opens in **Single / B152px / original sprite colors**. The original playground and all character artwork are preserved.

Click the **Light** button, or press **L**, to cycle:

1. Sprite colors: exact source colors, no scene darkening.
2. Dim room:35% ambient color, no point lights.
3. Lamp fill: the same dim ambient plus warm Godot PointLight2D fill.

This is a diagnostic of the existing painted sprite, not a proposed final lighting design. The strong lamp can over-brighten the pale skin while large clothing regions remain dark; it adds no authored cloth folds or missing material planes. No normal/specular maps, cast-shadow occluders or character shaders are used.

**Side by side / Single** retains one world and camera. A/B/C are128/152/160px at reset. Click a slot or press1/2/3; the64–240slider adjusts the selected slot. Space pauses; comma/period step frames; Speed cycles0.5×/1×/2×; G or Guides toggles measurement marks; R resets; M switches view; F11 toggles fullscreen. All actors share one1800ms idle clock.

The world is1200×480 in a1280×800viewport.152px is display height, not a change to the128×264native source or240pxrestbody. Whole-window scaling/fullscreen preserves in-world ratios. All source PNGs remain exact approved idle-r02 exports. Nearest sampling is retained.

The world lives on a separate CanvasLayer so light changes leave the interface readable. The procedural radial light mask is generated by GradientTexture2D at runtime; no new character or environment art was created.

Backdrop: Luis Zuno / ansimuz, GothicVania Church Pack, public domain. See CREDITS.md and ART-LICENSE.txt. The game's Silver Pines, Blasphemous and Hyper Light Drifter references are research illustrations only and are not used as playground assets.

RUN_CHECKS is absent in this user project. A separate copy ran19mouse/key/state checks and source-color/render audits. Research, observation limits and exact artifacts are in docs/experiments/2026-11-02-stealth-fighter-shadow-study-r01 in the containing repository.
