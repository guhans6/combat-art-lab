# Current A — supplied appearance variants

Five static looks share the same Quiet Keep background and152px rest-body height: Current A, user image1, image3, image4 and image5. Image2 is the reference sheet containing the exact image3 crop. Image3 and5 differ only in the shoulder cap.

- **Next set** cycles Original/1/3, Original/4/5, then Original/3/5 for the armor comparison.
- Click **A / B / C** to select a panel. Use the appearance dropdown underneath, or **‹ / ›**, to change that panel's look.
- **Single** shows only the selected panel's character in the middle bay. **Side by side** shows all3panels. World/camera stay fixed.
- The common height slider changes all panels together, keeping the comparison fair. Reset restores152px.
- **Light / L** cycles exact sprite colors, dim room and the existing strong lamp-fill diagnostic. Reset returns exact source colors. These are comparison settings, not a final lighting design.
- **Guides / G**, **Reset / R** and **F11** provide measurements, defaults and fullscreen.

Keyboard:1/2/3select the panel; Left/Right change its appearance; M switches view; N next set. The dropdown names retain the original attachment numbers. All figures, including Current A, hold their rest pose. No new animation is included.

The new sprites retain source-specific face, armor, hair, folds and lighting. Each has a separate layered native source in assets/source/stealth-fighter/user-variants-r01 in the containing repository, with exact PNG exports and reproducible pixel operations. They are comparison candidates; the user has not selected a final look. Existing approved idle and older playgrounds are retained.

152px is displayed body height, not a new native grid. Static sources use128×264canvas/240pxbody and nearest sampling. The world remains1200×480inside1280×800viewport; resizing/fullscreen scales the whole view.

Backdrop: Luis Zuno / ansimuz, public-domain GothicVania Church artwork. See CREDITS.md and ART-LICENSE.txt. No generated art or new environment assets were used. Source images are user supplied.

RUN_CHECKS is absent in this user project. A separate test copy checks mouse/key controls, the native OptionButton selection-signal route, rendered source colors, identical grounding and matched heights. Test capture explicitly requests drawing for the static scene. No automated UI actions run during normal use.
