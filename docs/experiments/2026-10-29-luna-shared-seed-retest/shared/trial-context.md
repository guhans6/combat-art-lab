# Scoped trial context

This context applies only to the shared sharp-seed retest. It supplies the minimum
project obligations without exposing prior contestants' operations, corrections,
coordinates, checkpoints, or comparative outcomes.

## Goal and scope

Construct and evaluate one editable static sprite through the bounded common-seed
trial described by `../BRIEF.md`. The test is limited to the declared 128×192 pixel
route. It is not a production promotion, general model ranking, motion test, Godot
test, or validation of other representation routes.

## Authorities and preservation

Use `fixture.json` for the exact common inputs and hashes. The approved scene and
close-up are identity/style authorities. The transparent full-character cutout is
supporting production geometry only. Inspect those originals, the seed, and actual
native export at native size and integer zoom. Preserve originals, shared fixture,
global configuration, and all unrelated work. Work only in the assigned trial
directory; retain all attempted passes and evidence.

## Required process boundaries

- Shared input files are immutable. In a trial working copy, authored cleanup is
  allowed only with the frozen palette and declared masks while preserving the fixed
  canvas, framing, and binary alpha policy. Do not re-prepare, requantize, crop,
  replace the seed, or change the palette control.
- Use only the existing authorized dedicated Aseprite MCP after the supervisor grants
  an editor slot. No UI automation, Code-MCP, generic Lua, direct Aseprite CLI, new
  image generation, extra agents, or peer communication.
- Keep native construction/editability evidence and visual decisions separate. Each
  pass requires its native source, export, operation record, and original/seed/best/
  candidate review at 1× and equal integer zoom.
- Record seed-use fitness, identity/expression observations, technical results, best
  eligible candidate, last candidate, and next baseline. A later pass is not selected
  merely because it is newer. User approval remains separate.
- Reopen and export the selected native source; demonstrate one useful localized edit
  on a labelled duplicate while protecting the candidate. Do not overwrite it.

Follow the experiment budget, checkpoint handoff, and defect-only supervisor loop in
`../BRIEF.md`. The broader workflow's representation-neutral intake applies outside
this pixel-route control; it does not change the frozen test inputs.
