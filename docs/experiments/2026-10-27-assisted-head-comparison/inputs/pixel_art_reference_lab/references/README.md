# Included references

These are byte-preserved conversation uploads, not a replacement for the repository's reference library. `manifest.json` records their dimensions, roles and hashes.

- `approved_concept_upload.png`: the original character/concept supplied in this conversation, 1448×1086. It carries the desired visual identity and aesthetic, not a mandatory native sprite grid.
- `supplied_sprite.png`: the supplied 128×192 reconstruction. Treat it as a baseline, not an authority over the original face or rendering.
- `supplied_head_comparison.png`: the supplied historical reference/baseline/candidate presentation.

The workspace also has approved scene, close-up and cutout files under `assets/references/approved-2026-10-26/`. Inspect them there; they were not all exported into this archive. Do not silently replace the native workspace images with a conversation-rendered copy. Compare hashes when identifying duplicates.

No newly generated poses, true turnaround, expression sheet or animation frames are bundled. Request or generate them only when they resolve the next experiment's actual need. The game screenshots that inspired the original direction and the workspace's `.aseprite` masters are not included.
