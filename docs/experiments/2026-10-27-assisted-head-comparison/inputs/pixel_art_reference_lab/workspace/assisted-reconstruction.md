# Assisted reconstruction — proposed director reference

**Trigger:** constructing native art from one or more references when tracing, source-derived pixels or a hybrid may reduce likeness drift. This is not a protected-correction benchmark.

## 1. Contract and inputs
Read the style contract and original references. Assign each supplementary image a role. Establish the initial native grid, framing, palette policy and bounded pass budget. Keep source and baseline files unchanged.

**Complete when:** paths/hashes, reference roles, visible invariants and the next hypothesis are recorded. No vague “match style” instruction substitutes for opening the images.

## 2. Acquire only missing evidence
Identify whether a pose, facial expression, visibility gap or excessive detail blocks the test. Generate a focused reference using available authorized tools and canonical attachments, or prepare an exact user prompt with attachment paths. Treat outputs as candidates. Preserve originals as the style/identity authority.

**Complete when:** the needed image exists and was inspected, or a concrete generation request is delivered with the dependent step explicitly pending. No imaginary image IDs or assumed attachments.

## 3. Select the assisted route
Trace silhouette/feature boundaries, transfer a reduced image and clean it, or combine both. Keep mapping and masks reproducible. Avoid adding extra detail merely because the source has it. Maintain the original face turn/expression unless the pose brief changes them deliberately.

**Complete when:** the first native seed/blockout is saved and visibly compared with the original and any intermediate reference. An imported seed is labeled as such.

## 4. Native finishing
Organize parts needed for meaningful revisions; draw or correct identity-bearing clusters. Preserve existing good regions. Read coordinates before patching; verify transparency and scoped writes. Newly generated details or hidden surfaces are proposed interpretations until reviewed.

**Complete when:** actual exported art and named native layers are inspectable, deviations are recorded, and a reasoned continue/correct/reject decision is made.

## 5. Review and revision proof
Review native size, integer zoom and stated display size. Judge aesthetic/identity/expression and technical validity independently. Demonstrate a localized native revision; reopen/export; use existing protected-native checks. A tiny pixel difference is not necessarily poor, and large similarity metrics are not artistic approval.

**Complete when:** candidate, source history, native checks, review images, unresolved defects and the next action are delivered. Human final selection is not fabricated. Stop at the bounded experiment boundary; get a better reference or change route if that is more useful than another unsupported micro-edit.
