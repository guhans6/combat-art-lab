# Evidence folders

`previous_conversion/` is the complete expanded historical `reference_conversion_study.zip`, with its method, source crop, native seeds, comparisons, reproduction script and prior verification unchanged. Its one-crop scope describes that old experiment, not a restriction on future multi-reference work.

`earlier_scale_comparison.png` and the two `*_croptest.png` files are prior conversation diagnostics, not new approvals or new native source files.

`seed_smoke/` was produced by this kit's new offline helper from the bundled original upload. The three decoded RGBA images match the corresponding historical seeds exactly. This validates that the helper carries through that diagnostic reduction; it does not establish likeness after native cleanup.

`normalization_smoke/` uses the same supplied sprite twice with a declared output offset of (6,-8). This tests stable placement and preservation of explicit movement, not pose generation or animation. `normalization_layout_smoke.json` reproduces it with actual included input paths. The processing record includes source hashes and frame durations supplied for the technical test.

The standalone template in `templates/` instead contains placeholder paths for a future real animation job. It is deliberately not presented as an already completed animation.
