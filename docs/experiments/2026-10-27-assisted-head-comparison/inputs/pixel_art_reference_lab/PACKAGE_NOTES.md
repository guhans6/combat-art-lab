# Package scope and provenance

This package collects the conversation's original uploads, previously generated diagnostics, current source-backed research synthesis, proposed workflow/skill additions, generation prompts and new offline preparation utilities. It is not a full backup of `/Users/guhan/Guhan/Projects/combat-art-lab`; native masters, original game screenshots and all private repository history remain there.

The latest user clarification governs the new workflow: multiple references and generated poses are allowed; fidelity means recognizable character, aesthetic and expression rather than exact source pixels. The older example README's single-image experiment is historical, not a new constraint. The old no-tracing/no-downsampling restriction should not be carried forward as a universal rule.

`IMAGE_PROMPTS.md` is a convenience compilation of `prompts/`; edit the per-task files when integrating. `INDEX.html` is an offline browsing page with relative links, no external scripts and no tracking. Source links are in `research/SOURCES.md`; third-party tutorials, models, fonts and implementation packages are not bundled.

Current scripts are original preparation utilities for this kit. They do not call image-generation APIs, install integrations or apply changes to the user's repository. `requirements.txt` records a tested dependency, not authorization to install globally. Use a separate new output directory for each test.

File checksums establish integrity of listed files, not authenticity of an art approval or correctness of every possible future operation. Generated references and finished native sources must still be inspected by the next agent and selected by the user where artistic judgment is required.
