## Portability and task-profile findings

The portable guidance is appropriately conditional: it documents copying the *entire*
folder into a chosen project's discoverable skill location, then requires discovery,
backend/runtime verification, and the scratch smoke test. It does not state that copying
installs the skill globally or proves availability. The skill's internal links are
relative; project-specific Luna/Sol/Terra routing stays in the project workflow.

`prepare_run.py` has no implicit profile argument. It copies and hashes named baseline
and references, validates the profile's native canvas, creates a task-specific mask,
and writes the task brief from `task_id` and the declared reference roles. The supplied
test covers a non-v03 expression profile. This establishes correct helper sourcing,
not Aseprite compatibility (the test deliberately uses synthetic native bytes).
