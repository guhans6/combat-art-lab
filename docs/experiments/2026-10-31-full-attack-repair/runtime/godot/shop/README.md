# Reusable first shop
Instantiate res://shop/shop.tscn. Its sixteen Sprite2D children have independent editable positions, visibility and image_path properties. Seven standalone prop scenes use local anchors: two pendants, two planters, a board and two ceiling emitters. The board and facade meet the original scene's left/top crop; these are camera-specific assets.
shop.gd exposes props_enabled and emitters_enabled. The emitter switch changes only light pixels: warm window illumination remains baked. No PointLight2D or glow effect has been implemented.
part_sprite.gd loads PNG bytes with Image.load_png_from_buffer into ImageTexture using the documented Godot 4.7 runtime API. This lets MCP-run previews consume new exports without an editor import step. Editor @tool behavior and packaged export are not exercised; a packaged game must retain raw PNG files in its export filters or adopt regular imported Texture2D resources.
main.tscn uses the independent shop plus untouched street-context textures and a separate residual context cutout. preview.gd automatically runs scoped visual checks once on startup, then resumes idle.
Verified through dedicated Godot MCP: sixteen loaded part textures, two independent instances, props hide/show, an eight-pixel planter move, emitter visibility and clean runtime output. Keyboard input is untested.
