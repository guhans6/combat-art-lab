## Instruction scenarios

| Condition | Required behavior | Procedure location |
| --- | --- | --- |
| Long strap is a separate owner and joins correctly under a front rim | Permit separate layers; inspect composite overlap and hidden route before deciding. Rejecting isolated floating appearance alone would be wrong. | §§1–3 |
| Bag turns edge-on; projected body width shrinks | Allow visually supported projection change; compare named sites/surfaces and same prop design. No constant-box test. | §3 |
| Far strap root is hidden behind fabric | Label inferred route on non-exported guide; examine near/far relationship and neighboring pose evidence. Do not require every root visible. Essential unresolved uncertainty still blocks continuation. | §§1,3–4 |
| A handle correction needs pixels inside explicitly protected bag owner | Record lock conflict; do not conceal with another overlay or silently broaden authority. Other authorized work may continue. | §2 |
| Shoe highlight edit preserves silhouette/attachments | Inherit structural evidence; normal scoped comparison/protection review suffices. No new full-body blockout. | Opening paragraph |
| Clean key but drifting intermediate pose | Review every affected exported frame and transition; key clearance does not imply cycle clearance. | §4 |
| Same wrong join after one correction, no new evidence | Change construction method within authority/budget or stop that branch. No cycle expansion, extra overlay or repeated favorable review as progress. | §4 |
| Technical checks pass; actual root-to-fabric relation remains uncertain | Revise/stop; report rejected diagnostic if needed, not improved animation ready for approval. | §4 |
| Agent cannot perceive continuous playback | Resolve static issues through stills; label remaining temporal gap and deliver playback candidate only if applicable structural gate passed. | §4 |
| User asks to see work in progress | Show clearly labeled diagnostic/rejected candidate with exact issue. Gate does not suppress requested evidence or invent approval requirements. | Delivery gate |
