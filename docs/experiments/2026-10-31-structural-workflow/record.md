## What changes in agent work

1. Before construction, record required relationships/affected frames and mark actual
   reference anatomy and persistent prop sites. Common height, family scale and
   layer names no longer serve as anatomical evidence.
2. Resolve difficult keys as simple connected forms before detail or propagation.
   Repairs include the affected seam and fabric surface, remove obsolete marks and
   choose near/far layer order from the intended overlap, within authorized scope.
3. Review actual composite, owner-isolated, owner-hidden and neighboring-pose views.
   Trace both ends of each handle. Check all affected exported frames after key
   clearance, then authored-speed review where perceptually available.
4. Record continue/revise/stop separately for proportions, attachments and continuity.
   Required uncertainty blocks expansion/positive delivery; revise within scope or
   report a failed experiment. This adds no user approval gate for routine corrections.
