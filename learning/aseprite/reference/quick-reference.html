Pick the right layer stack

Correct an existing sprite

  1. Corrections · visible, 100%
  2. Character art · visible, 100%
  3. Extra guides · hidden for export

Small color fixes belong on top. For deleting an original pixel, edit a duplicate of its owning source layer and hide the original.

Trace a replacement drawing

  1. My drawing · visible, 100%
  2. Guide · faded and locked

Hide the guide to see your actual drawing. Export only when the replacement artwork is complete enough for its intended use.

Ordinary guide versus special Reference Layer: an ordinary guide is editable image content and can appear in the PNG if visible. A special Reference Layer is non-drawable. This course uses ordinary guides and explicitly hides them. Layers ↗ · Reference Layer ↗

Before the PNG leaves Aseprite

  1. View the complete intended art at 100% zoom.
  2. Hide guides and temporary backgrounds. Keep a cleanup base visible.
  3. Save the layered .aseprite native master.
  4. Use File → Export → Export As… for a native-size .png.
  5. Reopen the PNG. Check dimensions, transparency and the edited feature.
  6. For Godot 4, use Sprite2D → Texture and CanvasItem Texture Filter → Nearest.

Vocabulary for this exercise: a sprite is the game’s 2D visual; a layer separates content; a cel is one layer’s picture on one frame; a native master preserves editable structure; a runtime export is the image the game consumes. These follow the project glossary and are a reading aid, not a claim of learned proficiency.
