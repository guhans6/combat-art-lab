Aseprite: the essentials

For a generated character image that needs safer editing, tracing, animation, and export. The game-scale resolution remains an experiment, not a fixed number.

Choose the right representation

You have…Use…Key limitation
Large concept imageReference layerGuide only; cannot paint onto it.
Small AI sprite PNGRegular editable pixel layerPixels are editable, but body parts are not automatically separated.
Layered master.asepriteKeep it as the editable source; don't replace it with only PNG.
Game importTransparent PNG / sprite sheetExport is not the same as native source.

Five-step safe edit

  1. Open the AI-base PNG; save a new .aseprite file.
  2. Duplicate the pixel layer, lock/hide the original, select the working copy.
  3. Add Layer → New → New Reference Layer from File.
  4. Fix one defect on the working pixel layer; compare with the reference and at native size.
  5. Save the master, then export PNG for the game/agent review.

Do not confuse three sizes. Canvas dimensions are the stored pixels. Zoom changes only editor view. Export resize changes output scale. A good in-game sprite needs deliberate art decisions, not merely fewer pixels.

One-minute quality check

  1. Does the tote silhouette read without zoom?
  2. Are the head-to-body proportions consistent?
  3. Are the feet at a stable shared ground contact?
  4. Is the background actually transparent?
  5. Can the .aseprite source reopen with the layers and frames you expect?
