# Aseprite learning lab

Optional, practical learning alongside the AI-authored [Combat Art Lab](../../README.md) pipeline. These lessons do **not** make hand-painting a prerequisite for production or settle the game's pixel resolution.

## Start here

1. Read [MISSION.md](MISSION.md) for the learning goal.
2. Open [Lesson 01: Correct one AI sprite](lessons/0001-correct-an-ai-sprite.html) in a **local browser**, after checking out this branch. It is a short hands-on lesson using an AI-generated base PNG and a higher-resolution reference.
3. Continue with [Lesson 02: Review six attack poses](lessons/0002-review-six-attack-poses.html) once you have six aligned PNG frames or a six-cell sprite sheet.
4. Keep the [printable Aseprite cheat sheet](reference/aseprite-quick-reference.html) handy.
5. Put outcomes and what you learned in [learning-records](learning-records/README.md) after practicing.

HTML lessons reference shared assets in \`assets/\`; opening the raw HTML file without its sibling folders will omit styling or checks. On GitHub, **Download raw file** or use the local checkout and open it in your browser.

## Inputs (supplied by you or the agent)

- AI-generated character pixel-base PNG, preferably already isolated on transparent background.
- Higher-resolution reference/concept image of that same pose.
- For Lesson 02: the six tote-bag attack poses (rest, grip, wind-up, strike, follow-through, recovery), if available.

## First tangible win

Save one corrected, layered \`.aseprite\` master and one transparent \`.png\` export; inspect it at native size. You are not expected to create the base art yourself.

No image assets, Aseprite installation, or Godot test are supplied or claimed by this branch. Target native resolution, palette, and approved look remain open. The AI workflow stays the owner of production asset construction.
