Lesson 01 · art direction → optional pixel correction

Correct one AI-generated sprite without redrawing it

Open the agent's pixel-sized base, keep a high-resolution tracing reference, and fix one mistake safely. Your first win is one editable pose and one transparent PNG.

First, understand pixel reduction

Aseprite can resize a sprite, but it cannot know which details must survive. If a concept image is 1000 pixels tall and your trial sprite is about 80 pixels tall, Nearest-neighbor downscaling samples pixels; it does not know that a tote handle or facial expression is important. 80 is just an example, not an approved project resolution.

Follow these steps

1

Open the pixel-sized AI base

Choose File → Open and select the AI-generated PNG. Immediately choose File → Save As and save idle-cleanup.aseprite. Your original PNG remains intact.

If you only have a large concept image: first save a working copy, then try Sprite → Sprite Size, keep the proportions locked, choose a trial width/height for your intended game view and Nearest-neighbor. Undo and test another size if the silhouette loses essential details. For better art, ask the agent to generate a deliberate low-resolution base instead of assuming resizing is enough.

2

Keep an untouched AI-base layer

Press Tab to reveal the timeline. Select the existing image layer, use Select → All, then Ctrl/⌘ + J to copy its selected pixels to a new layer. Name the new layer Working pixels. Lock and hide the original source layer with its timeline icons. Deselect the selection before painting.

If the imported PNG is an opaque Background layer, copying it to a transparent layer still copies its opaque pixels; remove unwanted background from the working image if you need a transparent game sprite.

Official Layers documentation covers copying a selection into a new layer and locking/hiding layers.

3

Put the large reference behind or beside the sprite

Choose Layer → New → New Reference Layer from File and select the higher-resolution character image. In the timeline, put that reference layer below Working pixels. Position it to align the torso, head, and feet; toggle visibility when needed. You cannot paint directly on a reference layer.

If the high-resolution reference does not align naturally, use it beside the sprite rather than tracing every pixel exactly; preserve the intended proportions and silhouette, not its full resolution.

Top row paints over lower rows. The reference and backup have different jobs. If a bad pixel is still visible, confirm you are changing the working pixels, not only adding an overlay over an unchanged error.

4

Repair just one visible mistake

Click Working pixels, press B for Pencil, zoom in using the wheel, and use a 1-pixel brush. Hold Alt and click to sample an existing color. Erase the bad pixels and replace them on the working layer.

Tote-bag practice: remove a stray outline pixel near the handle, restore the intended bag shape, or correct one oddly thick leg. For the very first practice, make only one correction so you can judge its effect.

5

Zoom back out and compare

Inspect at 100% or the approximate size it will be shown in the game. Then inspect enlarged to find stray pixels. Toggle the untouched base to compare before and after. Ask: is the body the same width, does the bag still read, and are the feet planted?

The enlarged image is for editing. The game-sized image is for the actual readability decision.

6

Save the editable source, then export

Choose File → Save to preserve idle-cleanup.aseprite. Then choose File → Export → Export As and export idle-cleanup.png. Verify the exported PNG's transparency and that the reference image does not appear in the export.

The native file is for future changes; PNG is a runtime/review output. Saving an imported PNG in the Aseprite format does not automatically split it into anatomical parts or construct a rig.

Your tiny challenge

Use the resting tote-bag pose and submit two screenshots (before / after) showing one changed detail, plus the .aseprite master and PNG export if you want the agent to review them. The result succeeds when the correction is visible and unrelated proportions remain unchanged.
