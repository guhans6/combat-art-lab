Lesson 02 / about 8 minutes

A smaller draft.
A separate drawing.

Your win: resize one concept, then trace just the outer side of the tote on a blank layer.

Use the original scene and close-up to check the character’s identity. The large cutout is a later AI-generated support image. It is convenient for sizing, but it has small design differences and is not a replacement for those originals.

Smaller is a choice, not a finish button

We use 128 × 192 only because this historical exercise already has that grid. There is no universal game-sprite size. A smaller grid may merge the eyes or lose fingers. You judge those losses at the intended display size before choosing a production resolution.

Part A · make a small draft

  1. Open a separate concept tab.Use File → Open for concept-cutout.png. It is 1024 × 1536. Use File → Save As… to create practice/my-resize-study.aseprite before changing it.
  2. Resize the image pixels.Use Sprite → Sprite Size…. Keep the aspect ratio linked. Enter width 128; height should be 192. Choose Nearest Neighbor as the resize method and confirm. Sprite Size ↗
  3. Read it at 100% zoom.Then zoom in. Crisp pixel boundaries do not guarantee good eyes, folds or edges. This manual resize may look different from the supplied converted draft: the historical pipeline also made crop/alpha/palette decisions. We are testing the control, not reproducing that recipe.

Part B · trace one small shape

  1. Turn the resized layer into a guide.Rename its row Guide — resize study through Layer → Properties. Set opacity to roughly 30% there (about 77 if your preference displays 0–255). Lock that row so you cannot paint on it accidentally. An ordinary guide is just an ordinary layer you choose to use as a visual aid. Layer controls ↗
  2. Put a new drawing layer above it.Use Layer → New → New Layer and name it My tote trace. Select its first-frame cell. Leave this drawing layer at 100% opacity and unlocked. The faded guide goes behind your drawing, exactly as you imagined.
  3. Trace only one outer tote edge.Use the 1 px Pencil to place a short contour. You can pick a dark bag shade from the full-opacity practice sprite in another tab. Aim for a readable outline rather than copying every shaded speck. Stop after one side.
  4. Hide the guide.Only your short line should remain on the checkerboard. That is success: you have separated a reference from your drawing. The whole character vanishing is expected because you have not drawn it yet. Show the guide again if you want to continue, and save the study.
What if the base is already converted by the agent?

Skip Part A. Open a copy of converted-seed.png. It is already 128 × 192. For tracing, fade and lock it as a guide. For correcting the existing sprite, keep its base fully visible and use the Lesson 1 cleanup stack. A faded base would also fade your exported character.

How do I put an image into an existing document?

For an aligned guide, first prepare the image at the same dimensions as the target. Open it in another tab, use Select All and Copy, return to the target, then Edit → Paste Special → Paste as New Layer. Move that row below your drawing. Check eye line, feet and bag placement before tracing. Matching document dimensions alone does not guarantee matching character proportions. Edit menu ↗

Keep a high-resolution identity reference open in a separate tab for comparison. Avoid repeatedly resizing your working sprite just to view that reference.

Is that the same as a special “Reference Layer”?

Aseprite also has Layer → New → New Reference Layer from File. That special layer can hold a high-resolution reference and cannot be painted on. Our exercise uses an ordinary layer so its visibility is explicit. Hide it before export and inspect the PNG. Do not rely on an assumed automatic exclusion rule for your installed build.
