Lesson 02 · animation review

Review your six tote-bag attack poses in Aseprite

Turn six image poses into a timeline, find shape/anchor mistakes and test timing. You are reviewing the agent's animation, not becoming responsible for drawing every frame.

Before loading: each frame should have the same transparent canvas dimensions, use the same scale and facing direction, and put the feet/ground anchor in a consistent location. If the AI files are mismatched, ask the agent to normalize and export them first. Do not individually squash/stretch characters to hide a proportions error.

Load the poses

1

Choose the import route that matches the files

If you have six numbered PNGs: name them consistently as frame0.png to frame5.png (or use an existing contiguous numbered sequence). Choose File → Open, select the first file, and answer Yes when Aseprite offers to load the sequence as one animation.

If you have a clean six-cell sheet: choose File → Import Sprite Sheet. Enter each pose's cell width/height, offsets, and any gaps. Verify the order. Avoid importing a collage with uneven cropped cells as if it were a regular sheet.

Sources: image sequences and sprite-sheet import.

2

Look at the timeline

Press Tab to show the timeline. Confirm the six poses are six frames rather than six layers overlaid in one frame. Click through frames 1–6 and check that a visible sprite appears in each. Save a working native file as tote-swing-review.aseprite.

Vocabulary: the row is a layer, the column is a frame, and their intersection is a cel. A cel contains the pixels you can edit for that frame.

Official Aseprite basics.

3

Compare adjacent frames using onion skin

Press F3 to enable onion skinning. Step between frames. Check whether the head size or torso width changes unexpectedly, whether the bag grows/shrinks, and whether planted feet slide in place. Onion skin makes the previous/next pose faintly visible as an editing reference.

Official onion skinning guide.

4

Test timing without guessing the final animation

Press Enter or the timeline Play button. Use Frame → Frame Properties (P) to change the time each frame remains visible. A frame is a drawing; its duration is the timing. Try making the strike read clearly, then restore your original values if it looks worse.

For this action, ask whether the wind-up builds anticipation, the tote moves toward screen-right through contact, and recovery feels controlled. This is a provisional art review; hitboxes and gameplay timing still need the Godot test.

Sources: animation preview and frame duration.

5

Save and hand the result back to the agent

Keep tote-swing-review.aseprite as the editable animation source. Choose File → Export Sprite Sheet for a PNG sheet or File → Export → Export As with a numbered PNG filename for separate frames. Review at intended display size and normal playback speed.

Give the agent exact feedback, for example: frame 4 tote grows too wide; the left foot slips between frames 3 and 4; preserve frame 1's torso proportions.

Your challenge

Find two issues, not ten. Identify one shape consistency concern and one motion/timing concern (or confirm that you did not observe one). Note the frame numbers. This is more useful to the agent than vaguely asking it to make the animation better.
Quick check: how can you hold the strike pose longer?
